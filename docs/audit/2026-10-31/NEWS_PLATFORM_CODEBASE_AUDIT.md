# News platform audit ? 2026-10-31

Status: IN PROGRESS / NO_GO. This is an evidence-based interim audit, not certification.
Base commit: 5686d95e6616ee45e02458a0f304c3623fa76365; branch: audit/news-platform-20261031. Existing uncommitted user changes are preserved. No deployment or production DB mutation performed.

## Scope and evidence
Repository contains Nuxt/Nitro + D1, a separate Go/Gin backend, Flutter mobile, SQL seeds, scripts and GitHub Actions. File presence is not runtime verification.

## Verified corrections
- RSS d1All parameters were nested arrays despite a variadic binding API. Corrected.
- RSS CDATA terminators could invalidate XML. Shared XML serializer and regression tests added.
- News sitemap included arbitrarily old articles when no recent article existed. Removed fallback; enforce 48 hours, exclude future/invalid dates.
- Feed ingestion could manufacture content and translations and tag every article as Bangkok. Replaced with provenance-only draft creation.
- Canonical origin trusted forwarded host headers. Removed request-header origin selection.
- Markdown fallback returned unsanitized HTML. Fail closed by escaping fallback text.
- Seven TypeScript diagnostics corrected.
- CI used Node 20 for Node strip-types tests and only checked migration text length. Updated Node 24 and execute actual migrations.
- CurrencyRates had an extra closing style tag causing production build failure. Removed premature tag.
